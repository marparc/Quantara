Quantara

Quantara is a simple currency exchange web app built as a portfolio project using Next.js, TypeScript, and Tailwind CSS. It integrates a forex API to display live exchange rates, historical data, and basic currency conversion.

The project focuses on frontend development, API integration, and clean UI design rather than production-level financial accuracy.

Tech Stack: Next.js, TypeScript, Tailwind CSS, REST API (external currency data source), Fetch / Axios

Features:
1.) Live Exchange Rates - Real-time currency rates with support for multiple currencies and a base currency (e.g. USD);
2.) Currency Conversion - Convert values between different currencies using live rates.
3.) Historical Rates - Fetch exchange rates for a specific date for basic comparison and learning purposes.
4.) Timeframe Data - Retrieve rates across a date range for simple analysis or charting.
5.) Currency Change Overview - Displays percentage change between two selected dates.
